# GlobalCart E-Commerce Sales Analytics Dashboard 🛒📊

## 📌 Project Overview
This project features a dynamic and interactive Excel dashboard designed for "GlobalCart," a growing e-commerce retailer. The dashboard transforms raw transactional data into actionable business insights, allowing stakeholders to track KPIs, analyze regional performance, and understand product category trends at a glance.

## 🎯 Business Problem
The executive team at GlobalCart needed a unified view of their sales and operational data to make data-driven decisions. The goal of this project was to build a tool that tracks overall revenue, identifies top-performing regions and products, and monitors customer satisfaction and delivery times, all while allowing users to filter the data dynamically.

## 🛠️ Tools & Technologies Used
*   **Microsoft Excel:** Data cleaning, processing, and visualization.
*   **Pivot Tables & Pivot Charts:** For aggregating and visualizing large datasets.
*   **Excel VBA (Macros):** Programmed a custom "Clear All Slicers" button to improve user experience and dashboard navigation.
*   **Data Modeling:** Connected multiple pivot tables to unified slicers for seamless interactivity.

## 📊 Key Dashboard Features
1.  **High-Level KPIs:** Instant visibility into Total Revenue, Total Orders, Average Order Value (AOV), Average Customer Rating, and Average Delivery Days.
2.  **Dynamic Filtering:** Interactive slicers allowing users to drill down by:
    *   Discount Group
    *   Region (East, North, South, West)
    *   Product Category (Beauty, Clothing, Electronics, Home)
    *   Payment Method (Card, COD, Wallet)
3.  **Revenue & Volume Analysis:** A dual-axis combo chart comparing Total Revenue (bars) against Volume Sold (line) across different product categories.
4.  **Geographical Insights:** A bar chart breaking down Total Revenue by Region.
5.  **Time-Series Trends:** A line chart tracking Revenue over months and quarters to identify seasonal trends.
6.  **One-Click Reset:** A VBA-powered macro button that instantly clears all active filters.

## 📂 Dataset Details
*   **Source File:** `E-Commerce Sales Analytics.csv`
*   **Key Columns Included:** `order_id`, `order_date`, `customer_id`, `product_category`, `region`, `quantity`, `unit_price`, `discount`, `payment_method`, `delivery_days`, `customer_rating`, `revenue`.

## 🚀 How to Use This Dashboard
1.  Download the `.xlsm` (Macro-Enabled Excel Workbook) file from this repository.
2.  Open the file in Microsoft Excel.
3.  When prompted, click **"Enable Content"** or **"Enable Macros"** so the "Clear All Slicers" button functions correctly.
4.  Use the slicers on the left-hand panel to interact with the data and watch the charts update dynamically!
